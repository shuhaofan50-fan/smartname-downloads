Chrome extension · Manifest V3

Messy download names,
replaced by the full title

The moment Chrome saves a file, SmartName Downloads names it from the page, paper, or image, and appends the date _YYYY-MM-DD.

  • Chrome built-in AI by default
  • On your device · free
  • Optional API key
a8f3e2c1.pdf
→Oral Nirmatrelvir for High-Risk, Nonhospitalized Adults with Covid-19_2026-11-01.pdf

Features

A real title is kept in full. If AI is unavailable, the page title is used immediately, so the download never waits. Duplicate names are numbered.

Chrome built-in AI

Gemini Nano runs on your computer by default. No account and no key. Desktop Chrome 138+; download the on-device model once from the options page.

Your own API

Optional OpenAI-compatible endpoint, such as DeepSeek, OpenAI, xAI, or a custom URL. The key stays on this device.

Enhanced recognition

Reads citation_title, Dublin Core, and Open Graph titles, plus a PDF's embedded title. For papers, only a PMC/PubMed id goes to NCBI, or a DOI to Crossref, to fetch the official title.

Manual install · Load unpacked

Load the extension/ folder from this repository:

  1. Clone shuhaofan50-fan/smartname-downloads.
  2. Open chrome://extensions and turn on Developer mode.
  3. Click Load unpacked and select the extension/ folder.
  4. Pin SmartName from the toolbar puzzle menu.
