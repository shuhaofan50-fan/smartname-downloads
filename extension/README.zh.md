# 智能下载命名 · SmartName Downloads（Chrome 扩展）

用浏览器自带下载时，自动用 AI 根据页面/图片/链接内容生成看得懂的文件名，并附加下载日期，例如：`猫咪在窗台晒太阳_2026-11-01.jpg`。

## 安装
1. 打开 Chrome，地址栏输入 `chrome://extensions`
2. 打开右上角「开发者模式」
3. 点击「加载已解压的扩展程序」，选择本文件夹 `ai-download-renamer`（zip 需先解压）
4. 点工具栏拼图图标，把「AI 下载命名」固定出来

## 命名引擎
- **Chrome 内置 AI（默认）**：Gemini Nano 本地运行，免费、无需 Key、不上传。需桌面版 Chrome 138+ 及足够硬件（约 22GB 空闲磁盘、16GB 内存或 4GB+ 显存）。首次需在设置页点「下载内置模型」。
- **自己的 API（可选）**：见下方。
- **基础命名**：都不可用时用页面标题/原文件名。
设置页可选：自动（推荐）/ 内置 AI / 自己的 API。
「增强识别」需授权读取网站数据，开启后可用页面标题和点击元素文字，命名更准。

## 设置 DeepSeek Key（可选）
1. 访问 https://platform.deepseek.com 注册登录，充值少量余额
2. 左侧「API Keys」→「创建 API Key」，复制 `sk-...`
3. 右键扩展图标 →「选项」，选 DeepSeek，粘贴 Key，点「测试连接」并「保存设置」（会请求访问该接口的权限，点允许）
也可选 OpenAI / xAI 或填写任意 OpenAI 兼容接口。Key 只保存在本机 `chrome.storage.local`。

## 说明
- 没填 Key 或 AI 超时（约 8 秒）时，会用页面标题/图片说明/原文件名命名，仍会加日期，下载不会卡住。
- 重名文件自动加 (1)、(2)。
- 若 Chrome 设置里开启了「下载前询问每个文件的保存位置」，保存对话框里会预填新名字。
- 其他扩展如果也修改下载文件名，可能冲突。

## Safari
Safari 的扩展接口不支持在下载时修改文件名（没有 `downloads.onDeterminingFilename`），所以本扩展暂不能用于 Safari。可行替代方案是 macOS 上用「文件夹操作 / 快捷指令」监听「下载」文件夹再重命名，后续可再做。
