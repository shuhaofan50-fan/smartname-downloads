# 隐私政策 — 智能下载命名（SmartName Downloads）
_更新日期：2026-11-01_

本扩展会在你下载文件时，把文件重命名为“可读标题 + 下载日期”。

**处理哪些信息：** 每次下载的文件地址、来源页地址、原文件名和文件类型。若你开启“增强识别”，还包括来源页面的标题/简介，以及你点击的图片或链接的文字。为获取论文的准确标题，扩展还可能在你的浏览器中重新读取来源页面以及 PDF 文件的开头/结尾部分（与网页本身一样使用你的登录状态），从中读取标题元数据。该过程完全在本地进行，读取的内容不会被保存或发送到任何地方。

**在哪里处理：**
- **Chrome 内置 AI（默认）：** 由 Gemini Nano 在你的电脑本地处理，不会发送给我们、Google 或任何第三方。
- **基础命名：** 本地处理，不发送任何数据。
- **自己的 API（可选）：** 仅当你填写自己的 API Key 时，上述信息会发送给你选择的 AI 服务商（如 DeepSeek、OpenAI、xAI），仅用于生成文件名，适用该服务商的隐私政策。

**论文信息查询（仅增强识别）：** 当下载的文件像是学术论文时，扩展可能只把它的公开编号——PubMed/PMC 编号发送给 NCBI E-utilities（eutils.ncbi.nlm.nih.gov），或 DOI 发送给 Crossref（api.crossref.org）——以查询官方标题。不会发送 Cookie、个人信息或文件内容。

**存储什么：** 设置、你填写的 API Key（可选）和最近 5 条重命名记录，仅保存在本机 `chrome.storage.local`，卸载即删除。

**我们不做：** 无账号、无自有服务器、无统计分析、无追踪、无广告，不出售或共享任何数据；从不读取或上传文件内容。
