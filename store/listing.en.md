**Detailed description:**
Tired of downloads named a8f3e2c1.pdf, IMG_20261101_093512.jpg or download (3).zip? SmartName Downloads renames every file the moment you download it — using the real title of the paper, article, product or video, plus the download date.

  a8f3e2c1.pdf → microRNA exploration of proliferation pathways in stem cells_2026-11-01.pdf

✨ Free & private by default — uses Chrome's built-in AI (Gemini Nano), which runs entirely on your computer. No account, no API key, nothing uploaded.
📄 Keeps the full title — never truncated or summarized; a short description is generated only when there is no real title.
📅 Date stamp — YYYY-MM-DD or YYYYMMDD.
🔑 Bring your own AI (optional) — DeepSeek, OpenAI, xAI or any OpenAI-compatible endpoint.
🎯 Enhanced recognition (optional) — uses the image caption / link text you clicked for even better names.
⚡ Never blocks downloads — falls back to page-title naming instantly; duplicate names are numbered automatically.
🔒 Minimal permissions — only "Manage your downloads" at install.

Note: Chrome built-in AI requires desktop Chrome 138+ and supported hardware; otherwise basic naming or your own API is used.
